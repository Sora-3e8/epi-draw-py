Install
===========================================================

### Linux/Unix:

To install execute in terminal:
  ```
  git clone https://github.com/Sora-3e8/epi-draw-py
  ./venv_install.sh
  ```
To run: 
  ``` 
  ./main.py 
  ```

### Windows:

  Open cmd as administrator and run:
  ```
  git clone https://github.com/Sora-3e8/epi-draw-py
  start venv_install.bat
  ```
To run: 
  ``` 
  start launch.bat 
  ```
